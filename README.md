# HAJIN OFFICE · 하진 통합 관리시스템

회사 소개 홈페이지와 한국어 업무 관리 웹앱입니다. 첫 화면에는 브랜드 소개, 업무 영역, 일하는 방식이 표시되며, 오피스 바로가기 버튼으로 통합 관리 화면에 진입합니다. 회사 소개 문구는 초기 제안용으로 작성되어 실제 회사 소개에 맞게 조정할 수 있습니다. Node.js 20 이상만 필요하며 외부 패키지 설치가 필요 없습니다.

## 실행

```bash
cd /workspace/-HAJINOFFICE
npm start
```

기본 포트는 3000이며 `PORT=3001 npm start`로 변경할 수 있습니다. 서버는 0.0.0.0에 바인딩됩니다.

## 기능

- 종합 대시보드: 예산·프로젝트·영업 지표, 예산 그래프, 오늘의 일정
- 재정·예산: 편성·집행·잔액 관리, 초과 예산 표시
- 운영 일정: 월별 캘린더, 날짜별 일정, 월 이동
- 분석: 실제 입력 데이터에서 집계한 예산·영업·프로젝트 분석
- 프로젝트: 담당자·상태·진척도·마감일·우선순위 관리
- 영업 파이프라인: 5개 단계별 고객 관리와 단계 변경
- 항목 추가·수정·삭제, 현재 화면 검색(종합 화면에서는 전체 검색), 전체 JSON 내보내기, 예시 데이터 초기화

## 데이터와 범위

최초 화면은 명시적으로 표시된 예시 데이터입니다. 일정 예시는 최초 실행 시점의 현재 월에 생성됩니다. 데이터는 브라우저 localStorage에 저장되어 새로고침 후 유지됩니다. 브라우저·기기·접속 주소별로 분리되며 여러 사용자가 공유하지 않습니다. JSON 내보내기는 백업용이며 가져오기 기능은 포함하지 않습니다.

현재 버전에는 로그인, 권한 제어, 서버 데이터베이스, 회계 시스템 연동이 없습니다. 실제 회사의 민감한 데이터를 여러 사람이 관리하려면 인증·권한과 서버 저장소를 먼저 추가해야 합니다. 외부 Google Fonts를 불러오지 못하면 시스템 글꼴로 표시됩니다.

## 검증

```bash
npm run check
```

브라우저에서는 새 항목 등록 → 수정 → 새로고침 후 유지 → 검색 → 삭제를 확인할 수 있습니다. 예산과 영업 금액을 변경하면 대시보드와 분석 수치도 함께 갱신됩니다.

## 정적 호스팅 배포

`public` 폴더의 index.html, app.js, style.css를 정적 호스팅에 업로드하면 됩니다. 별도 서버나 빌드 과정이 필요하지 않으며 하위 경로 호스팅도 지원합니다. 배포 패키지는 `/workspace/artifacts/hajin-website.zip`에 준비되어 있습니다.

Netlify Drop(https://app.netlify.com/drop)에서 로그인한 뒤 ZIP을 풀어 생성된 폴더를 업로드하면 공개 HTTPS 주소가 발급됩니다. 실제 배포는 호스팅 계정에서 수행해야 합니다. 접속 주소가 달라지면 localStorage 데이터도 별도로 시작합니다. 이 패키지에는 브라우저에 입력했던 데이터나 인증 정보가 포함되지 않습니다.

## 기존 AS 시스템 연결

홈페이지 상단 메뉴·업무 영역 카드·하단 링크에서 기존 Cloudtype AS 시스템을 새 탭으로 엽니다. 통합 오피스의 AS 관리 메뉴에서도 진입할 수 있습니다. 기존 서비스의 인증과 데이터 저장을 그대로 사용하며, 홈페이지와 로그인이나 데이터를 통합한 것은 아닙니다. 외부 서비스 응답과 가용성은 별도로 확인해야 합니다.
